# Mission

This project is a decentralized, IPFS-style vector database built on Bittensor. It serves as a permanent semantic memory layer for AI agents.

## Core Directives
1. **SDD Compliance:** All changes must be validated against `spec/features/` plans and `tasks.md`.
2. **Context Integrity:** Maintain `context7.json` as the source of truth for architectural status.
3. **Architecture Focus:** Prioritize backend, security, and protocol performance.
4. **No Fluff:** Ignore cosmetic UI or marketing tasks.
